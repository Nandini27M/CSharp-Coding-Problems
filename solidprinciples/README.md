# CSharp SOLID Principles

This repository contains C# projects demonstrating SOLID Principles.

## Projects

### 1. Hospital Management System
Concepts:
- SRP (Single Responsibility Principle)
- OCP (Open Closed Principle)

Features:
- WhatsApp Notification
- Credit Card Payment
- Medical Report Service

### 2. Library Management System
Concepts:
- ISP (Interface Segregation Principle)

Features:
- Faculty Membership
- Email Alerts
- SMS Alerts

### 3. Ride Sharing Application
Concepts:
- OCP
- DIP (Dependency Inversion Principle)

Features:
- Luxury Ride
- Bike Ride
- Auto Ride
- WhatsApp Notification
- Dependency Injection
