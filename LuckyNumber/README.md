# Lucky Number

## Problem Statement

A non-prime positive integer x is called a Lucky Number if:

S(x²) = S(x) × S(x)

where S(n) is the sum of digits of n.

Find the number of Lucky Numbers between m and n.

## Sample Input

20
30

## Sample Output

4
