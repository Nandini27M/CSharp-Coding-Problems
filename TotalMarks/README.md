# Total Marks

## Problem Statement

There are two types of questions in an exam.

- Type 1 questions carry X marks.
- Type 2 questions carry Y marks.

There are N1 questions of Type 1 and N2 questions of Type 2.

Given the total score M, determine whether it is possible to obtain that score.

If multiple solutions exist, display the solution with the maximum number of Type 1 questions answered correctly.

## Sample Input

5
8
5
4
44

## Sample Output

Valid
4
3

## Technologies Used

- C#
- .NET 10
- Loops
- Conditional Statements
