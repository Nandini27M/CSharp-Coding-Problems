# Lucky String

## Problem Statement

A string is called a Lucky String if it contains a substring of length n that:

1. Contains only P, S and G.
2. Contains at least n/2 consecutive identical characters.

Print:
- Yes → if the string is lucky
- No → if the string is not lucky
- Invalid → if n is greater than the string length

## Sample Input

8
FGHPSGGGGPPSABD

## Sample Output

Yes
