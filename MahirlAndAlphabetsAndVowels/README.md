# Mahirl And Alphabets And Vowels

## Problem Statement

Remove all consonants from the first word that are also present in the second word.

After removal, if two or more consecutive characters are the same, retain only the first character.

Comparison is case-insensitive.

## Sample Input

Aaaabcc
bcd

## Sample Output

A

## Technologies Used

- C#
- .NET 10
- String Manipulation
- StringBuilder
